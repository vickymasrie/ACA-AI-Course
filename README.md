# ACA AI Course — AI for PMs

Workspace for coursework from ACA's "AI for PMs" course. This is where I build and collect
projects, skills, and products as I go through the course.

## Structure

- **`projects/`** — hands-on exercises and build projects from course modules. One subfolder per
  project.
- **`skills/`** — reusable Claude skills I create (prompts, workflows, or packaged capabilities
  built during the course).
- **`products/`** — more polished, product-shaped outputs (prototypes, specs, demos) that go
  beyond a single exercise.

Each subfolder should have its own short README describing what it is and its current status.
